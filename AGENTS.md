# Working rules

- Read `PLAN.md` and `STATUS.md` before continuing this project. Read the original GDD for design intent; do not overwrite it.
- Current scope: a Godot 3D singleplayer chase prototype and then a short complete MVP, with third-person camera, WASD/mouse, and physical travel across a large robot to change modules.
- Use the agreed 48-hour scope. Prove traversal and module interaction before producing final art. Co-op, online play, full ragdolls, procedural levels and complex enemy AI are deferred.
- Resume from the first unfinished verified milestone after an interruption. Check the working tree first and preserve existing work. Do not restart or duplicate already running work.
- At every meaningful checkpoint update `STATUS.md` with completed work, verification, known limitations and the exact next step. Commit source/assets/docs and push to origin/main without force. Never commit credentials, generated engine caches or builds.
- A local rule cannot wake a stopped chat. Hourly continuation uses the Codex thread automation. Do not create background scripts or duplicate schedules to bypass usage limits. Respect user stop requests and access limits.
- Separate static checks, automated gameplay checks and observed visual/playability checks in reporting. Never describe untested interaction as validated.
